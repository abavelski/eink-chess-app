# Sashité Western Chess pieces

These 12 SVG files are the First Player (white) and Second Player (black)
Western pieces from https://sashite.dev/assets/chess/. The source describes
them as public domain; they are used here under CC0 1.0. The SVGs are kept
unchanged. `generated.rs` converts their paths to Cobalt's 1000-unit vector
format while preserving the SVG fill layers.

Regenerate with `python3 scripts/generate_sashite.py`.
